# Privacidade e sanitização

## Regra principal

Este repositório documenta a solução técnica, não o banco de pessoas atendidas.

## Nunca publicar

Não devem ser enviados para o repositório:

- nomes reais;
- telefones;
- e-mails;
- documentos de identificação;
- endereços;
- dados de abrigo, pensão ou situação individual;
- respostas reais do formulário;
- currículos reais;
- links privados de Google Forms, Sheets, Docs ou Drive;
- IDs de arquivos ou pastas de produção;
- tokens, chaves ou credenciais;
- exportações da planilha;
- capturas de tela que revelem dados pessoais.

## Dados de demonstração

Para testes e exemplos, utilizar somente dados fictícios claramente identificados como demonstração.

Exemplo:

```text
Nome: Pessoa Exemplo
Telefone: (00) 00000-0000
Cidade: Cidade Exemplo
Objetivo: Serviços gerais
```

## Repositório público

Antes de tornar qualquer repositório público, revisar o histórico do Git e os arquivos adicionados. Remover também dados que tenham sido publicados em commits anteriores.

## Ambiente de produção

A planilha e os documentos reais devem permanecer nos ambientes institucionais autorizados, com permissões adequadas e acesso restrito à equipe responsável.

## Princípio de minimização

Coletar somente as informações necessárias para o atendimento, geração do currículo, organização do banco de talentos e encaminhamento profissional.
