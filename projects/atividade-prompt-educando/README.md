# Atividade — Criação de Prompt para o Meu Primeiro Currículo

## Contexto

Atividade realizada no Programa de Preparação para o Mundo do Trabalho (PMT), utilizando Inteligência Artificial como ferramenta de apoio à construção do primeiro currículo profissional.

O educando foi orientado a criar um prompt capaz de conduzir uma IA na elaboração de um currículo para uma oportunidade de Jovem Aprendiz, utilizando informações verdadeiras e preservando a autonomia do estudante.

## Objetivos

- Desenvolver a capacidade de formular prompts.
- Compreender a importância de contexto e instruções claras.
- Organizar informações pessoais e profissionais.
- Reconhecer competências e experiências.
- Utilizar IA de forma responsável.
- Compreender a diferença entre gerar conteúdo e orientar uma IA.

## Estratégia da atividade

O educando foi orientado a informar no prompt:

- objetivo profissional;
- formação;
- cursos;
- conhecimentos;
- experiências;
- projetos;
- competências;
- interesses profissionais;
- regras para evitar invenções.

A atividade também estimulou a criação iterativa: criar o prompt, testar, observar o resultado e realizar melhorias.

## Regra de veracidade

> **Profissionalizar a linguagem sem alterar a realidade.**

O prompt deve orientar a IA a utilizar apenas informações fornecidas pelo estudante e a fazer perguntas quando houver dados insuficientes.

## Conexão pedagógica

A atividade trabalha autonomia, organização do pensamento, comunicação e autoconhecimento. O estudante precisa compreender o que deseja comunicar antes de orientar a IA.

A lógica pedagógica utilizada é:

**Pensar → organizar → orientar → testar → avaliar → melhorar.**

## Produto da atividade

O produto final é um prompt elaborado pelo próprio educando, registrado em versão sanitizada para documentação pedagógica do projeto.
