# Prompt Base — Construção de Agente de IA: Meu Primeiro Currículo

## Finalidade

Este é o prompt-base utilizado para iniciar, no ChatGPT, a construção gradual do agente de IA **Meu Primeiro Currículo**, voltado aos educandos do Programa de Preparação para o Mundo do Trabalho (PMT).

## Prompt

> Construção de Agente de IA – Meu Primeiro Currículo
>
> Atue como um especialista em criação de agentes de IA para educação profissional de adolescentes.
>
> Vamos construir, passo a passo, um agente chamado **Meu Primeiro Currículo**, voltado para jovens de 14 a 17 anos do Programa de Preparação para o Mundo do Trabalho (PMT).
>
> O objetivo do agente será ajudar o jovem a desenvolver seu primeiro currículo, especialmente para oportunidades de Jovem Aprendiz.
>
> Neste momento, quero construir gradualmente:
>
> - Objetivo do agente
> - Público-alvo
> - Função principal
> - Comportamento esperado
> - Método de interação
> - Perguntas que o agente deverá fazer
> - Regras e limites
> - Critérios para avaliar as informações fornecidas pelo aluno
> - Estrutura do currículo
> - Formato das respostas
> - Regras de privacidade e segurança
> - Diretrizes pedagógicas
> - Prompt final para implementação no Gemini
>
> ### Importante
>
> - Faça uma etapa por vez.
> - Não antecipe todas as etapas.
> - Após cada etapa, apresente a proposta e aguarde minha revisão.
> - Não invente informações sobre o projeto.
> - Faça perguntas quando uma decisão de configuração for necessária.
> - Priorize linguagem clara, profissional e adequada para adolescentes.
> - O agente deve estimular autonomia e reflexão, e não simplesmente escrever tudo pelo aluno.
>
> Comece pela primeira etapa.
>
> Apresente uma primeira proposta curta para eu revisar.

## Observação de documentação

O prompt acima é o **prompt de partida da construção do agente**. Ele estabelece o método de desenvolvimento antes da elaboração das instruções finais do GEM.

A estratégia central é:

**Prompt base → construção etapa por etapa → revisão → consolidação → Prompt Mestre → implementação no Gemini.**
